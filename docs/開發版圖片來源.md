# 開發版圖片來源

這批圖片是依照現有網站架構，從團隊提供的 Google Drive 素材庫挑選，
僅供開發階段展示。正式上線前仍需由昊道團隊確認人物肖像與公開使用授權。

目前的影像原則是：不使用老師照片；共學相關頁面在取得公開同意前不使用人物照；
「認識昊道」與「學習地圖」不以靜坐畫面代表整體昊道文化。
各地共學點目前使用的是自然意象，並非實際場地照片。

網站用檔案在轉換成 WebP 時不保留 EXIF、相機與 GPS 資訊。
